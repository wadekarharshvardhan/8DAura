First-time setup

Connect your Windows audio.

VB-CABLE creates the virtual audio route 8D Aura listens to. Download it from the official VB-Audio site, then connect it to your headphones in the app.

Get VB-CABLE from VB-Audio ↗

The driver installer needs administrator approval. 8D Aura does not install drivers automatically.

01

Download and extract

On the official page, download the Windows VB-CABLE driver ZIP and extract it into a folder.

02

Install the audio driver

In the extracted folder, right-click VBCABLE_Setup_x64.exe, choose Run as administrator, then follow the installer. Restart Windows after installation.

03

Route Windows audio through the cable

In Windows Settings → System → Sound, set the output device to CABLE Input (VB-Audio Virtual Cable).

04

Choose your headphones in 8D Aura

Open 8D Aura. Set Capture from to CABLE Input and Output to to your headphones or earbuds. Press Start real-time 8D.
